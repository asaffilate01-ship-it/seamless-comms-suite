# Omniqora AI & Intelligence

A private pilot for company workspaces, product-scoped agents, seven-stage guided journeys, approvals, evidence and EPOS intelligence.

See [Integration and activation](docs/INTEGRATION.md) for implemented behaviour, API contracts, limits and commercial launch requirements.

Verification: `node --test tests/workflows.test.mjs` and `node node_modules/typescript/bin/tsc --noEmit`.

Live AI requires a configured server provider key. Samples are scripted. This service has not yet been merged into the existing Omniqora or other portfolio repositories.
